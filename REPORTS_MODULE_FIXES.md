## How to Use

### 1. Install New Dependency

```bash
cd backend
pip install reportlab==4.0.7
```

### 2. Restart Backend

```bash
python main.py
```

### 3. Test PDF Downloads

**Full Report:**
1. Go to Reports module
2. Click "Download PDF Report" button
3. PDF will download automatically with all data

**Individual Incident:**
1. Go to Reports module
2. Click "View Details" on any incident
3. Click "Download Incident Report" in the modal
4. PDF will download with full incident details

## Troubleshooting

### PDF Download Fails
- Check backend logs for errors
- Ensure reportlab is installed: `pip install reportlab`
- Verify `/tmp` directory exists and is writable
- Check browser console for errors

### Indicators Still Show N/A
- Ensure alerts have `details` field in MongoDB
- Check that endpoint agent is sending full telemetry
- Verify backend is extracting details correctly

### 7-Day Chart Shows No Data
- Ensure there are alerts in the database
- Check date range filter
- Verify alerts have valid timestamps
- Check backend logs for date parsing errors
